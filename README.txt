LA VIE DANS LES VILLAGES UKRAINIENS — VERSION PREMIUM
Présentation HTML A2 · 8 diapositives · environ 5–6 minutes
Date affichée en bas : 04 novembre 2026

DÉMARRAGE
Ouvrez index.html dans Chrome ou Edge.
Cliquez sur ⛶ en haut à droite ou appuyez sur F.
En plein écran, tous les contrôles et éléments superflus sont cachés.
La date reste discrètement en bas, comme demandé.
Flèches gauche/droite, Espace, Page Up/Down : changer de diapositive.
Home/End : début/fin. Échap : quitter le plein écran.

IMPORTANT — PHOTOS
Les photographies authentiques sont chargées depuis Wikimedia Commons.
Une connexion Internet est nécessaire pour les afficher.
Si une photo ne charge pas, un paysage SVG illustratif local apparaît.
Ce paysage de secours n'est PAS une photo réelle.
Le blason de Nastashka est utilisé sur la diapositive dédiée :
aucune photo d'un autre village n'est présentée comme Nastashka.

POUR GITHUB PAGES
1. Ouvrir ce dossier dans VS Code.
2. Dans le terminal :
   git init
   git add .
   git commit -m "Presentation villages ukrainiens"
   git branch -M main
3. Créer un dépôt GitHub vide, puis :
   git remote add origin https://github.com/VOTRE_COMPTE/NOM_DU_DEPOT.git
   git push -u origin main
4. GitHub : Settings > Pages > Deploy from a branch > main / (root).
5. Patienter quelques minutes puis ouvrir l'URL affichée.
